# ArcaneByte

A small Python script that randomly generates a tabletop RPG-style character. Each run
picks a fantasy race, a class, a sex (male or female), and rolls six ability scores
(strength, dexterity, constitution, intelligence, wisdom, charisma), each between 8 and
20, then prints the result to the console.

## Status

This is an old, single-file personal script (first written in 2024). It has not
received functional changes since, only a filename cleanup. There are no tests, no
configuration options, and no packaging beyond the one script.

## Requirements

- Python 3
- No external dependencies — the script only uses the standard library `random` module.

## Usage

```
python Personaggio.py
```
